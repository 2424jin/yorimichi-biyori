# よりみち日和 — 行きたい場所から旅のしおりを作る

行きたい町と場所を選ぶと、日帰りでも泊まりでも、回る順と時間のプラン（旅のしおり）ができるサイトです。

## 使い方（3つの画面）
1. **行き先と日数**：町の名前・日帰り／1泊2日／2泊3日・着く駅（任意）・1日に動く時間を決める
2. **行きたい場所を選ぶ**：町の中心から20 km以内の観光地を、一覧と地図から「しおり」に入れる
3. **プラン**：近い所どうしを同じ日にまとめ、回る順・時刻・ごはん休憩・泊まるエリアの目安を出す

`index.html` をブラウザーで開きます（地図と場所さがしにはインターネット接続が必要です）。

## ファイル
- `index.html`：サイト本体（3つの画面）
- `spots-curated.js`：手で選んだ観光地
- `wikidata-spots-lite.js`：Wikidata（CC0）から集めた観光地（使う項目だけの軽い版。元の全部入りは `過去の版/2026-11-26_wikidata-spots_full.js`）
- `spots-added.js`：足した京都の観光地（位置は日本語版Wikipediaの座標。記事のURLを各行に記録）
- `events.js`：例年のイベントの目安
- `過去の版/`：作り直す前のページ（2026-11-11）

## 目安について
- 移動時間・費用は、直線距離から出した目安です（1.8 km以内は歩き、それより遠いと電車・バス）。
- 滞在時間は場所の種類からの目安です。営業時間・料金・電車の時刻は、公式の情報やGoogleマップで確かめてください。
- 宿のデータは無いので、「泊まるエリアの目安」までを出します。
- しおりは、そのブラウザーの中だけに保存されます。

## 使っているサービス
- 地図：Leaflet・MapLibre・OpenFreeMap（OpenStreetMapのデータ）
- 場所さがし：Photon（OpenStreetMapのデータ）
- 天気：Open-Meteo
