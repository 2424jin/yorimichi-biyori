# よりみち日和 — 全国お出かけプラン

北海道から沖縄まで、日本各地のおすすめスポットを地図から探し、現在地または駅・空港など旅行先周辺の天気を確認して、お出かけプランを作れる日本語サイトです。スマートフォンにも対応しています。

## 開き方

`index.html` をブラウザーで開いてください。インターネット接続があればLeaflet、MapLibre GL JS、OpenFreeMapの無料道路地図を表示します。ライブラリや地図タイルを読み込めない場合は、ページ内の日本列島概略図に自動で切り替わります。地図または一覧のスポットを選ぶと `spot.html` の詳細ページへ移動し、プラン作成後は `plan.html` に結果を表示します。`route.html` は経路検索、`places.html` は近くのお店・施設検索、`events.html` は季節イベントの絞り込み一覧です。これらのページはスポット・イベント詳細から出発地、目的地、移動手段を引き継いで開けます。初回表示時に現在地の許可を確認し、許可された場合は現在地を中心に20 kmの範囲を表示します。拒否した場合も地名の手動検索やスポットからの出発地設定を利用できます。天気・近隣検索にはインターネット接続が必要です。`file://` で位置情報を使えない場合は、HTTPSまたはlocalhostで開いてください。

## 機能

- OpenStreetMapデータを使ったOpenFreeMap道路地図上に全国27,039か所のおすすめスポットを表示（通信できない場合も概略図で継続）
- 手作業で選定した観光・余暇スポットと、Wikidataの日本語名・座標・分類を使ったスポットを収録。神社、公園、山、島、博物館、美術館、滝、動物園、劇場など、観光名所または余暇を過ごせる施設に限定
- さらに100か所を追加。白金青い池、秋田ふるさと村、四季彩の丘、東京消防庁消防博物館、東京都水の科学館、なばなの里、倉敷アイビースクエア、大塚国際美術館など、各地方の自然景勝地・文化施設・レジャー施設を拡充
- 市区町村名だけの項目や一般駅は除外し、空港と乗換・新幹線停車などの主要駅はおすすめスポットに収録
- 全国の神社、観光スポット、文化施設、自然景勝地、レジャー施設を地図と一覧に表示し、種別で絞り込み
- 科学館、劇場、屋内アクティビティ、動物園、商業施設など、時間を過ごしやすい施設を53か所追加
- 東北・関東・中部・近畿・中国・四国・九州・沖縄の美術館、動物園、体験施設、公園などをさらに50か所追加
- `places.html` で現在地または駅・住所の近くにある映画館、飲食店、大型施設、スーパー、コンビニを種類別に検索。検索条件と候補を左右に分け、場所やジャンルの選択だけでは通信を開始せず、サイト内検索または同じタブで開くGoogle マップ検索を選べる
- 47都道府県すべてに少なくとも1か所のスポットを収録
- 27,039件の一覧は初回100件ずつ表示し、検索・種別絞り込み（主要駅・空港を含む）・前後ページ送りで候補を探せる
- 地図をドラッグ・ズームし、マーカーまたは一覧を選択すると地図上にスポット名・説明・出発地からの所要時間目安・滞在・費用と「詳しく見る」ボタンを表示
- スポット詳細ページで場所の種別、出発地からの距離・所要時間目安、スポット地点の天気を確認
- スポット詳細で出発地を駅名・住所から検索、または現在地に設定し直し、移動手段も切り替えてアクセス目安とGoogle マップの経路を更新
- 季節イベントのカードから専用のイベント詳細ページへ移動し、概要・例年の時期・会場周辺へのアクセス・最新の公式情報検索を確認
- スポット・イベント・プラン画面に「ひとつ戻る」と「最初の画面へ」のナビゲーションを用意
- 経路検索ページと季節イベント一覧ページを追加し、地図・スポット詳細・イベント詳細・プラン結果を共通ナビゲーションで行き来
- スポット詳細・イベント詳細の出発地や移動手段を引き継いで、専用の経路検索ページで条件を調整
- スポット詳細ページに近隣イベント候補と当日サッカーの地域検索・公式日程リンクを表示
- 旅行先の地名・駅名・空港名を入力して周辺検索（例：神戸空港）
- 東京タワー、東京スカイツリー、横浜ランドマークタワーなどの展望施設、テーマパーク、水族館、博物館、屋内体験施設を追加
- 地名・駅名・住所の入力中にPhotonの候補を表示。マウスまたは上下矢印・Enter・Escapeで操作可能
- 経路の出発地・目的地も入力候補から選択でき、出発地欄の現在地ボタンから現在地を設定
- 現在地または検索した場所の周辺観光スポットをOpenStreetMapから追加取得し、近い順に最大50件を表示
- 50・100・200 km・全国の距離検索、地図上の距離範囲円、および移動手段別の所要時間目安検索（30分・1時間・1時間30分・2時間）
- 時間検索では選択した所要時間と移動手段から半径を概算し、距離検索と同様に地図へ円で表示
- ブラウザーの現在地取得、現在地周辺の天気・気温表示
- 「現在地を使う」を押すと距離検索を20 kmに戻し、地図を現在地中心の近隣表示へ移動（概略図でも同じ範囲にズーム）
- 位置情報を使えない場合は選択したスポットを出発地に設定して近隣検索・天気・プランを利用
- 出発時刻と終了時刻を設定し、その枠内で移動・乗換待ち・行列待ち・施設種別ごとの滞在時間を含む行程を作成（終了時刻が開始より早い場合は翌日として扱う）
- 3時間以上の行程には、最初の立ち寄り先の近くで45分の食事休憩を自動で追加し、時間と1人あたり1,500円の費用目安に含める
- 作成した行程は独立した `plan.html` の結果画面に表示し、場所・時間・費用を別カードに分けて確認。タイムラインでは立ち寄り順に加え、区間ごとの出発・到着時刻、移動・乗換待ち時間、経路リンクを分けて表示
- 予算入力は任意。各スポットの到着・待ち・滞在の時刻目安と、Google マップの電車経路・時刻確認リンクを表示
- 出発地・目的地・移動手段を指定した Google マップ経路検索。スポット詳細の経路・地図リンクは新規ウィンドウに依存せず、現在のタブで開く
- 選択したスポットを出発地・到着地に設定し、場所検索または経路をGoogle マップで直接開く
- Google マップで公共交通の経路・発車時刻を確認する導線
- Google Flights で航空便を検索する導線
- 外部地図ライブラリやタイルが読み込めない場合にも表示できる概略図

## 外部サービスとデータの制約

道路地図はLeaflet、MapLibre GL JS、OpenFreeMapの公開タイル（OpenStreetMapデータ）を使い、APIキーなしで表示します。地図上のOpenFreeMap・OpenMapTiles・OpenStreetMap帰属表示を残してください。OpenFreeMapの[利用条件](https://openfreemap.org/tos/)を確認してください。地図サービスが使えない場合は、全国の位置関係を示す概略図を表示します。

天気は無料のOpen-Meteo APIから取得し、APIキーは不要です。メイン画面ではブラウザーの現在地または利用者が選択した出発地、スポット詳細画面ではスポットの座標を天気取得のためOpen-Meteoに送信します。スポット詳細へ移動する際、選択したスポット、出発地の座標・ラベル、移動手段をブラウザーの `sessionStorage` に一時保存し、詳細画面でアクセス目安を計算します。この情報はこのサイトのサーバーには送信しませんが、同じタブのセッション中はブラウザーに保持されます。周辺スポット検索と `places.html` の店舗・施設検索では、検索地点を[Overpass API](https://overpass-api.de/)（OpenStreetMapデータ）に送信します。場所候補にはPhotonを利用します。どちらも公開サービスのため、応答速度や継続提供は保証されません。店舗・施設のサイト内検索はユーザーが実行した場合のみ開始し、応答待ちは最大5.5秒、同じ条件の再検索はページ内キャッシュを使います。検索条件に応じたGoogle マップの周辺検索ボタンは常時表示され、サイト内検索中やAPIタイムアウト後もすぐに外部の候補一覧を開けます。取得できない場合も、収録済みの27,039か所は利用できます。店舗・施設の検索結果はOpenStreetMapの登録内容に依存し、未登録の施設は表示されません。距離・時間検索では範囲内の収録済みスポットを近い順にすべて対象とし、100件ずつページ表示します。「全国」を選ぶと登録済みの全国スポットすべてを検索・一覧表示できます。OpenStreetMapから追加する周辺候補は最大50件で、登録状況や通信状況によって表示件数が変わります。

おすすめスポットは、手作業で選定した863件と、[Wikidata](https://www.wikidata.org/)から日本語ラベル・座標・観光／余暇に関係する分類を抽出した26,176件で構成しています。Wikidataのデータは[CC0](https://creativecommons.org/publicdomain/zero/1.0/)で提供されています。追加スポットの `area` 表示（地方・都道府県）は、[GeoNames](https://www.geonames.org/)の日本行政区分データと都道府県庁所在地の座標を使って割り当てています。GeoNamesデータは[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)に基づき利用しています。市区町村名だけの項目や一般的な交通拠点は追加データから除外し、手選定の空港と主要駅を収録しています。Wikidataの分類や座標は利用者・編集者による登録に基づくため、施設の営業状況、一般公開、立ち入り可否、観光価値を保証するものではありません。訪問前に現地の公式情報をご確認ください。各追加スポットのIDはWikidata項目の識別子です。現在の収録数は27,039件で、50,000件の目標には未達です。追加候補の取得先がアクセス制限・タイムアウト中のため、未検証の項目や地名で件数を水増ししていません。

地図上の円は、距離検索では選択した距離（例：50 km）の直線距離範囲、所要時間検索では選択時間と移動手段から算出した概算半径を示します。所要時間検索は実際の道路経路・公共交通の発車時刻・乗換を取得した等時間圏ではありません。実際の所要時間はGoogle マップで確認してください。

旅行先検索と入力候補、スポット詳細での出発地検索にはPhotonの公開デモAPIを利用します。APIキーは不要ですが、継続提供や応答速度の保証はありません。2文字以上の入力を少し待ってから候補検索し、入力された地名をPhotonへ送信します。検索は一定間隔に制限し、同じ語句の候補はページ内で再利用します。Photonへ接続できない場合も、入力内容で周辺検索を続けられます。Photonの利用条件と[OpenStreetMapの帰属表示](https://www.openstreetmap.org/copyright)を確認してください。

行程の出発・到着時刻、移動・乗換準備・費用・滞在時間は、距離、選択した移動手段、スポット種別や施設名から算出する計画用の概算です。時刻入力と行程内の時刻・所要時間は5分単位に切り上げています。地図から選んだスポットはプランの最初の立ち寄り先として優先されます。費用は交通費と入場料等を分け、交通費は移動手段別の距離目安（経路距離は直線距離に移動手段別の係数を掛けた概算。公共交通は基本180円＋経路距離1 kmあたり25円、車は燃料等16円/kmと駐車目安400円、自転車は150円＋5円/km、徒歩は0円）から算出し、10円単位に丸めます。高速料金・実運賃・スポットごとの最新入場料は取得していないため、施設料金も種別や名称による目安であり、実額とは異なる場合があります。テーマパークは長め、水族館・博物館などは中程度の滞在時間を初期値にし、現地の実際の所要時間・待ち時間を示すものではありません。3時間以上の行程には最初のスポットの近くで45分の食事休憩を組み込みます。食事候補はGoogle マップ検索へのリンクで案内し、店舗情報や営業状況をサイト内で取得しているわけではありません。食事費用は1人あたり1,500円の目安です。実際の電車の発車時刻・乗換・運行状況を取得するAPIは接続していません。各区間のGoogle マップリンクを開き、プランで設定した時刻に合わせて実際の経路を確認してください。スポット詳細画面のアクセス所要時間も、選択した移動手段と直線距離を使った概算であり、実際の経路検索結果ではありません。季節イベントは `events.js` に収録した例年の開催時期をもとにした候補です。イベント詳細ページから概要・会場周辺の地図・公式情報の検索を確認できますが、今年の開催日・開催有無は確定していません。主催者の公式情報で確認してください。当日のサッカー試合を自動取得するAPIは接続していないため、日付・地域を指定した検索とJリーグ公式日程へのリンクを案内します。施設の行列・料金・営業状況も取得しません。航空便はGoogle Flightsで確認してください。掲載スポットの施設情報の最新性も保証しません。
